# thebigcrafter organization configuration

This repository contains the public organization profile and the compatibility-maintenance configuration used by thebigcrafter projects.

The organization focuses on PocketMine-MP plugins and libraries. Project repositories keep their own workflow, dependency, release and documentation decisions; this repository only provides the shared upstream watch and organization profile.

See [MAINTENANCE.md](MAINTENANCE.md) for the update-watch procedure and [maintenance-baseline.json](maintenance-baseline.json) for the exact tested baselines.
